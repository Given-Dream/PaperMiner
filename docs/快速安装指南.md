# PaperMiner - 完整安装指南

## 推荐：使用单文件 Setup

v1.4.2 推荐从 GitHub Release 下载 `PaperMiner-v1.4.2-Setup.exe`。安装目录可以是 `D:\PaperMiner`、`E:\Apps\PaperMiner` 等任意可写子目录；为避免误覆盖文件，不能直接安装到磁盘根目录。

Setup 会读取 `conda env list --json`，因此 Conda 主程序与 `MinerU` 环境可以位于不同磁盘或使用自定义 `envs_dirs`。安装成功后记录的是环境的真实路径。

## 系统要求

### 硬件要求

- **操作系统**: Windows 10/11
- **内存**: 8GB+（CPU 模式建议 16GB+）
- **存储**: 至少 5GB 可用空间（模型约 2GB）
- **显卡**（可选）: NVIDIA GPU（支持 CUDA 加速）

### 软件要求

- **Conda**: Anaconda 或 Miniconda（安装路径不限，C:/D:/E: 均可）
- **网络**（首次安装）: 用于下载依赖和模型

## 推荐安装方式：一键安装

双击 **`一键安装.bat`**，脚本会自动完成所有配置。

### 一键安装会做什么？

1. **检测 Conda** - 自动搜索常见安装路径；找不到时提示手动输入路径
2. **创建 Python 环境** - 创建名为 `MinerU` 的 Conda 环境（Python 3.12）
3. **智能安装 PyTorch** - 自动检测 GPU 驱动版本，选择匹配的 CUDA 版本（cu126/cu121/cu118），安装后验证 CUDA 可用性，不兼容时自动降级为 CPU 版
4. **安装 MinerU** - 安装 PDF 提取核心引擎
5. **安装其他依赖** - ttkbootstrap 2.x、pandas、openpyxl、python-docx 等
6. **配置模型源** - 选择 ModelScope（国内）或 HuggingFace（国际），MinerU 3.0+ 首次运行时自动下载模型
7. **创建桌面快捷方式**

### 常见安装问题

**Q: 提示"Conda not found"？**

脚本会让你手动输入 Conda 安装路径。例如你装在 D 盘，输入 `D:\Anaconda3` 回车即可。不需要配置系统环境变量。

**Q: PyTorch 下载很慢？**

GPU 版 PyTorch（约 2.5GB）必须从 PyTorch 官方源下载，无法使用国内镜像。请耐心等待，安装是一次性的。

**Q: 首次处理 PDF 很慢或报错 LocalEntryNotFoundError？**

MinerU 3.0+ 首次运行会自动下载模型（约 2GB）。`运行程序.bat` 已自动设置使用国内 ModelScope 源。如果仍失败，可手动下载：

```bash
conda activate MinerU
set MINERU_MODEL_SOURCE=modelscope
mineru-models-download --source modelscope --model_type pipeline
```

**Q: 已经安装过了，再运行会重装吗？**

不会。脚本会自动检测已安装的依赖，全部就绪时提示"Already installed"，默认跳过。

## 手动安装（高级用户）

如果一键安装不适用，可按以下步骤手动安装。

### 1) 创建并激活环境

```bash
conda create -n MinerU python=3.12 -y
conda activate MinerU
```

### 2) 安装核心依赖

**必需依赖**（PDF 处理、提取功能）：

```bash
pip install -U "mineru[core]"
pip install pandas openpyxl beautifulsoup4 python-docx lxml
```

**可选依赖**（章节提取 LLM 功能）：

```bash
pip install requests python-dotenv
```

**说明**：

- 不安装 `pandas`、`openpyxl`：表格只保存 JPG，不生成 Excel
- 不安装 `python-docx`：不生成 Word 文档
- 不安装 `requests`、`python-dotenv`：章节提取仅使用正则模式（90% 成功率）
- 其他功能不受影响

### 3) 安装 PyTorch（CPU / GPU 二选一）

CPU 版本：

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```

GPU 版本（根据驱动版本选择对应 CUDA 版本）：

| GPU 驱动版本 | 推荐 CUDA 版本 | 安装命令 |
|-------------|---------------|---------|
| >= 560 | cu126 | `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126` |
| >= 525 | cu121 | `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121` |
| >= 520 | cu118 | `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118` |
| < 520 | CPU 版 | 驱动太旧，建议使用 CPU 版本或更新驱动 |

注意：GPU 版 PyTorch 必须从 PyTorch 官方源下载（约 2.5GB），国内 pip 镜像只有 CPU 版。

提示：

- 运行 `nvidia-smi` 查看驱动版本号（如 560.35）
- 一键安装脚本会自动检测驱动版本并选择匹配的 CUDA 版本
- 参照 [PyTorch 官网](https://pytorch.org/get-started/locally/) 选择匹配版本

### 4) 配置模型源（MinerU 3.0+）

MinerU 3.0+ 首次运行时会**自动下载**模型（约 2GB），无需手动下载。只需设置模型源：

```bash
# 国内用户（必需，否则默认访问 HuggingFace 会失败）：
set MINERU_MODEL_SOURCE=modelscope

# 国际用户（默认）：
set MINERU_MODEL_SOURCE=huggingface
```

`运行程序.bat` 已自动设置 `MINERU_MODEL_SOURCE=modelscope`，直接双击启动即可。

如需手动预下载模型：

```bash
set MINERU_MODEL_SOURCE=modelscope
mineru-models-download --source modelscope --model_type pipeline
```

### 5) 验证安装

```bash
mineru --help
```

### 环境重置（若安装出错）

```bash
conda deactivate
conda env remove -n MinerU
conda clean -a
pip cache purge
# 然后重新从步骤 1 开始
```

或者使用 `清理重装.bat` 一键清理。

## 安装后配置

### 配置 LLM 接口（可选）

不配置也能使用所有功能。配置后章节提取成功率从 90% 提升至 98%。

**方法一（推荐）**：启动程序后点击右上角“设置”，然后选择：

- **DeepSeek**：输入 API Key，点击“测试连接与速率”，验证后保存。
- **自定义接口（OpenAI 兼容）**：填写 API 根地址和 API Key，点击“连接并获取模型”；成功后勾选模型、选择默认模型，可再逐模型测速，最后保存。部分本地接口可不填 Key。

自定义接口需提供 `GET /models` 和 `POST /chat/completions`。测速会发送一次很小的真实推理请求，可能产生少量费用。修改自定义 API 地址或 Key 后，必须重新连接验证。

**方法二**：在项目根目录复制 `.env.example` 为 `.env`，填入 Key：

```env
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-your_deepseek_api_key_here
DEEPSEEK_MODEL=deepseek-chat
```

**获取 API Key**：[DeepSeek 平台](https://platform.deepseek.com/)

- 注册账户 -> 充值（最低 10 元）-> 创建 API Key
- 平均成本：< 0.0003 元/篇

## 启动和使用

### 启动程序

双击 `运行程序.bat`，或双击桌面快捷方式 `PaperMiner`。

### 基本使用流程

#### 模式 1: 完整处理（推荐）

1. 将 PDF 文件放入 `input/` 文件夹
2. 在 GUI 中选择处理选项（文字/公式/图片/表格/章节）
3. 点击"开始处理"
4. 查看结果：`output/extract/[PDF名称]/`

#### 模式 2: 仅提取

适用于已运行过 MinerU，只想重新提取内容的情况：

1. 选择"仅提取（从已有 raw 文件夹提取）"
2. 勾选需要的内容
3. 点击"开始处理"

## 常见问题

### 环境问题

- `conda: command not found` -> 安装 Conda，或在 Anaconda Prompt 中运行
- `mineru: command not found` -> 运行 `conda activate MinerU` 后重试
- 程序启动提示"环境检测"有问题 -> 运行 `一键安装.bat` 修复
- GUI 缺组件 -> `pip install python-docx`

### 网络问题

pip 安装超时：

```bash
pip install -U "mineru[core]" -i https://pypi.tuna.tsinghua.edu.cn/simple
# 或
pip install -U "mineru[core]" -i https://mirrors.aliyun.com/pypi/simple
```

### 运行与模型问题

- `LocalEntryNotFoundError` -> 模型未下载或网络不通。确认 `运行程序.bat` 中已设置 `MINERU_MODEL_SOURCE=modelscope`，重试即可
- GPU 显示不可用 -> 运行 `一键安装.bat` 会自动检测驱动版本并安装匹配的 PyTorch GPU 版本；如仍失败会自动降级为 CPU 版
- 首次处理慢 -> MinerU 3.0+ 首次运行自动下载模型（约 2GB），属于正常现象
- PyTorch `FutureWarning` -> 可忽略，不影响运行

### 章节提取问题

**Q: 不配置 API Key 能用吗？**
A: 能用。正则模式覆盖 90%+ 的标准论文。

**Q: 为什么没有触发 LLM？**
A: 说明正则提取质量很好，这是正常现象。

**Q: LLM 会修改内容吗？**
A: 正则模式和轻量分类模式不修改原文。全量提取模式可能调整格式，建议对比原文检查。

**Q: 自定义接口连接成功后如何选择模型？**
A: 模型列表出现后勾选一个或多个模型，再选择默认模型。保存后，主界面的“LLM 模型”下拉框可在这些模型间切换。

**Q: 能获取模型列表，但测速失败怎么办？**
A: 检查该模型是否开放聊天补全权限、账户余额是否充足，以及服务是否兼容 `/chat/completions`。

### 重装/清理

运行 `清理重装.bat`：

- **轻度清理**：删除环境和缓存，保留模型（重装最快）
- **深度清理**：全部删除，包括 2GB 模型（需重新下载）

## 智能章节提取详解

### 三层策略

| 层级 | 方式 | 速度 | 成本 | 触发条件 |
|------|------|------|------|----------|
| 第 1 层 | 正则表达式 | <10ms | 免费 | 始终执行 |
| 第 2 层 | LLM 标题分类 | 1-2s | ~0.0005 元 | 发现未识别标题 |
| 第 3 层 | LLM 全量提取 | 10-30s | ~0.002 元 | 提取质量不合格 |

### 性能统计

| 指标 | 正则表达式 | LLM | 混合策略（当前） |
|------|-----------|-----|-----------------|
| 成功率 | ~90% | ~95% | **~98%** |
| 平均速度 | <10ms | 10-30s | **~500ms** |
| 平均成本 | 免费 | 0.002 元 | **0.0002 元** |

### 质量检查触发条件

| 检查项 | 触发条件 | 处理方式 |
|--------|---------|---------|
| 完全失败 | 未提取到任何章节 | LLM 重新提取 |
| 缺少关键章节 | 缺少 Abstract/Introduction/Methods 等 | LLM 补充缺失 |
| 内容过短 | 章节内容 < 100 字符 | LLM 重新提取 |
| 数量异常 | 提取章节 < 2 个 | LLM 重新提取 |
